# CustomAgents

A collection of small local-first apps and tools, each in its own folder:

| Project | Description | Run |
|---|---|---|
| [job-search-aggregator](job-search-aggregator/) | Local-only AI-powered job search aggregator (.NET 9 API + Angular 20 frontend, Postgres/Redis via Docker) | `.\scripts\start.ps1` (see [job-search-aggregator/README.md](job-search-aggregator/README.md)) |
| [money-tracker](money-tracker/) | Self-contained static-HTML expense/money tracker | `.\scripts\start.ps1` (see [money-tracker/README.md](money-tracker/README.md)) |
| [resume-builder](resume-builder/) | Self-contained static-HTML ATS resume builder | `.\scripts\start.ps1` (see [resume-builder/README.md](resume-builder/README.md)) |

Each project has its own README with prerequisites, setup, and run instructions — see the links above.
